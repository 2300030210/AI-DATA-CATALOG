# Atlas — AI Data Catalog

A lightweight, interactive demo of an AI-assisted data catalog. Explore sample
assets, search in natural language, filter by domain or asset type, and run a
local metadata-discovery pass to classify the item awaiting review.

## Run locally

Open `index.html` in a modern browser. No build step, dependencies, or backend
are required.

The catalog uses sample data and local keyword/synonym matching to demonstrate
discovery and search workflows. It does not connect to enterprise data sources
or use a hosted AI model.
